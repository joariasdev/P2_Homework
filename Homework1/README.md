# Homework 1

En esta ocasión decidí cambiar la estructura jerárquica presentada por el maestro.

## Justificación:

- Iniciamos con la clase **User** como clase principal.
- **Employee** y **Student** heredan de la clase **User**.
- **Graduate** hereda de las clases **Student** para representar un estudiante graduado y reutilizar las propiedades de **Student**.
- **Teacher** y **Staff** eran de **Employee** para distinguir entre docentes y empleados administrativos.
